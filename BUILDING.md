# Building the compiled ports

This repository now contains the source-preparation and build machinery recovered from the AmigaChrome game-port workstream.

## 1. Prepare exact upstream source

The catalog pins every source by full Git commit or archive SHA-256.

    python3 scripts/game_port_prepare.py prepare --root . --game all
    python3 scripts/game_port_prepare.py verify --root . --game all

Prepared source is placed below `build/game-ports/sources/`, which is intentionally ignored by Git.

## 2. Provide an AROS m68k SDK

Set:

    export AROS_SYSROOT=/path/to/AROS/Developer
    export AROS_CC=/path/to/m68k-aros-gcc
    export AROS_CXX=/path/to/m68k-aros-g++
    export PATH="$(dirname "$AROS_CC"):$PATH"

The successful AmigaChrome build used the local AROS m68k SDK generated by the scripts under `toolchain/aros-local/`.

The default CPU target is 68040. Override with `CPU=68020` or `CPU=68030` for compatibility experiments.

## 3. Build a port

Examples:

    sh ports/chocolate-doom/build.sh build/game-ports/sources/chocolate-doom
    sh ports/sdlpop/build.sh build/game-ports/sources/sdlpop
    sh ports/openjazz/build.sh build/game-ports/sources/openjazz
    sh ports/nxengine-evo/build.sh build/game-ports/sources/nxengine-evo
    sh ports/uqm/build.sh build/game-ports/sources/uqm/uqm-0.8.0

The CMake ports generate their portable AROS toolchain and SDL2/SDL2_mixer imported-target shims through:

    scripts/create_aros_cmake_env.py

## 4. What has actually been proven

The five ports above have produced m68k AROS executables on the original AmigaChrome build workstation.

That proves **compile/link success only**.

Runtime first-light on AmigaChrome Instance-22 is still pending. Until that happens, the repository deliberately labels these ports COMPILED rather than TESTED.

## 5. Game data

No proprietary game data is fetched into Git or bundled in this repository.

Local first-light testing currently uses:

- Freedoom for Chocolate Doom
- Jazz Jackrabbit shareware for OpenJazz
- Cave Story freeware data for NXEngine-evo
- the SDLPoP project runtime data / two-level PoP demo reference
- the official UQM 0.8 base content package

Those assets stay outside source control.
