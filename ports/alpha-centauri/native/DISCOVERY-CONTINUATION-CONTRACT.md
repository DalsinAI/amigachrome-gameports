# Original discovery continuation boundary

Private original-instruction observations, not a restored discovery award. The
parent owned reactor sequence remains unchanged. No UI, portable continuation,
research award, session mutation or native execution is added here.

## Local reactor suspension

The original base caller enters at `0x5d2a03`. After all ordered reactor proposals,
it requests presentation only when its best-reactor accumulator is nonzero,
MapOwner equals the awarded faction and multiplayer is inactive. At `0x5d2b90`
it calls parse_say with argument 0, the actual full reactor name, -1 and -1. The
next real call at `0x5d2b9c` requests REACTORUPGRADE with argument 0. Its return
value is unused, but its real presentation effects have not been recovered.

This suspension precedes the last-created reset, auto-design branch and cache
invalidation. Preserve the intermediate last-created and upgrade scratch words;
the two cache words still contain their pre-event values. A completed nonlocal
plan's final -1 cache/cursor getters cannot represent this suspended point.
There is no permission to rewrite MapOwner or multiplayer to skip the request.

Twelve actual original-prefix contexts ran with complete unmodified proposer,
retirement, history, make, naming, pruning and upgrade helpers. Eight reached the
parse call and four naturally reached the no-popup boundary. Every mapped global
byte and the four runtime words matched independent expected results. Observer
jumps stop before parse or the no-popup continuation; no dialog return is supplied.

## Generic discovery order after the reactor stage

The base post-reactor region begins at `0x5d2c4e`. Its first mandatory presentation
branch is taken for the MapOwner faction or when GameState has omniscient bit
0x80. Local discovery detail, sound, popup/window and their lifetime remain real
unimplemented obligations. A nonlocal, non-omniscient context naturally skips
that branch; this is a supported observation domain, not a substitute authority.

The subsequent order is:

1. Secrets monument history, when technology flag 1 is set. The real nonlocal
   helper naturally returns without its local monument presentation.
2. Local-only tutorial, prototype/social and associated choice paths.
3. First map-reveal effect for flag 8: map visibility and visible item snapshots,
   base visibility and population intelligence, then faction reveal bit 0x200.
   Already-revealed factions do not refresh these snapshots.
4. Complete technology-effect cache recomputation.
5. Local-only interludes and their actual dependencies.
6. Datalinks first, then the ordered TECHSHARE recipient scan.
7. The final first-Secrets notification, after recursive sharing returns.

The base original has no Thinker FREEFAC/FREEABIL loops at this position. Do not
insert mod effects into an original award without a separate edition contract.

## Sharing is recursive, not an unordered closure

Sharing excludes technology 88 and uses the original disabled-prerequisite
asymmetry. Datalinks uses project index 11, not facility 81 as an array index.
Its recipient must be a positive base owner missing the technology, and at least
three factions 1..7 must know it. The first base recursive award call is at
`0x5d35f9`, with source -1 and share argument 0.

The base TECHSHARE scan considers recipients 1..7 in order, checks each positive
configured threshold against all known owners 1..7, and calls at `0x5d3717` with
source -2 and share argument 1. A nested award changes ownership and runs its own
effects before the parent scan resumes. Neither callback nor recursive award is
replaced here. SMAX has additional expansion/infiltration/pact/Empath/Governor
conditions; inspection of those conditions is not SMAX execution qualification.

The tail at `0x5d3732` uses the real current turn and the caller's captured
first-ever fact. A first-ever Secrets technology requires a notification even
when nonlocal. Setting its notification bit alone cannot complete discovery.
Bonus advancement belongs to the outer research caller and remains separate.

## Actual private validation

A contiguous base post-reactor region ran in 64 synthetic contexts, with actual
Secrets, game_year and technology-effects helpers as reached. All 720896 mapped
global bytes and 20 boundary bytes matched an independent Python interpretation.
There were eight generic-presentation boundaries, two first Datalinks requests,
twelve first TECHSHARE requests, and 42 pre-first-Secrets-tail boundaries. No
helper bytes were changed. Four explicit observer jumps stop before a real
presentation branch, nested award call or the first-Secrets tail and never return.

The 12-context local reactor proof and 64-context continuation proof are separate
entry-frame observations. They do not demonstrate a whole tech_achieved call,
constructor/destructor lifecycle, full PE startup, GUI/import/network callback,
recursive award, SMAX continuation or active-session authority. Inputs are
synthetic declared runtime facts, not facts inferred from an original save.

No C++ continuation implementation, new host/68040 portable suite, SDK binary or
native qualification is claimed. All inherited source/workflows are unchanged.
The next owning implementation must model a genuine suspended presentation plus
resume/lifetime contract, or close a complete strictly nonlocal continuation and
nested-award domain with every required effect. Until then the award stays held.
