# Owned discovery notification content — pending, host qualified

This additive stage expands the original pending reactor/first-Secrets request
into bounded owned caption and body text. It is not a completed presentation or
technology award. The original continuation, intermediate World, parser context,
and owner resource remain unchanged; there is no acknowledge/resume/award API.
A real UI lifecycle and subsequent log/object cleanup are still mandatory.

`original_expand_template` reconstructs the resolved string subset of original
`parse_string` (SMAC 0x633160, SMAX 0x625880). It accepts explicit observed
language mode, supplied parser slots and a bounded NUL-terminated template.
Ordinary labels select their decimal slot suffix; `$$` escapes a dollar. M/F/N
and slot grammar selectors use the recovered plural/gender alternative rules.
For example M1 selects masculine singular alternatives; it is not a speech or
music command. Selected slot alternatives are copied as bytes, not recursively
interpreted. French contraction mode1, numeric/# selectors, links, malformed
syntax and unsafe grammar accesses remain held. This is a bounded subset, not a
complete replacement for every original formatter mode. Maximum owned result is
8191 bytes plus NUL. Every output/input alias and wrapped span rejects before
writes, and failure preserves the previous result.

`discovery_notification` consumes a prepared `DiscoveryPresentationText` and
explicit resolved current SCRIPT filename/bytes. It selects the exact resource
key and owns expanded caption, source body lines, `#xs` width and original caret
style codes. Supported stock resources are REACTORUPGRADE and THESECRET0/1;
current inherited World continuation reaches local reactor and nonlocal
first-Secrets requests only. This does not invent a local Secrets continuation
past the still-held generic presentation. Only xs/caption and a simple body are
supported. Unknown/audio directives, button/menu bodies, duplicate/late fields,
missing resources and capacity overflow reject transactionally. Source caret
style codes follow inspected original popup initialization at 0x61afa0; they do
not claim that the original layout, wrapping, font metrics or popup ran.

The three owner SCRIPT sections have no audio directive. Consequently this
owned request does not select or automatically play a technology quote. This
says nothing about original generic-discovery audio, ambient music or UI sound
side effects. Existing original-font and explicit technology-voice playback
routes remain separate; no new font choice, audio device or UI hook is added.

## Validation and boundaries

Private complete original helpers returned in 184 contexts for each edition,
including actual owner SCRIPT caption/body templates and synthetic grammar,
byte-string and escape controls. Both produced identical output SHA256
`fa7c96423b52d169cdfe781b2aa47ed961d69ebdfb8913faa4ea79076808c3a4`.
All 720896 mapped global bytes per case remained unchanged. Real reached
string/findnum routines executed; no imported callback or helper was replaced.
The declared entry precondition includes an initially empty output string.
An earlier harness omitted that precondition and is explicitly disqualified,
preserved privately rather than presented as proof.

The independent owned leaf has 204 host ASan/UBSan and actual independent
Linux68040/QEMU controls, identical output SHA256
`7235e939da34542a02b87417af7ac0a2c12657423ddf1550e14f19b3bcbd20e5`.
The connected probe retains all 173 inherited World/continuation/context cases,
112 producing actual prepared pending content and 61 preserving earlier typed
boundaries. It checks complete current decoded state, opaque baseline,
transactional aliases/failures, original SCRIPT bytes, output ownership and
pending state. Added caret/invalid directive/capacity controls do not simulate UI
outcomes. Final host and independent68040 receipts are private; no owner text,
original executable bytes or private vectors are included in Git.

Normal SDK probe builds are build-only. Native/GUI/audio integration is UNRUN.
Watch/lab, frontend, session authority, original log/destructor outcomes and
recursive awards are untouched. Real UI results must retain identity with the
pending source event and preserve its staged intermediate state; simply setting
a boolean or returning a fabricated original popup result is not completion.
Stack capacity for the bounded content/expansion temporaries must be qualified
before native integration. No full discovery/turn/gameplay claim is made.
