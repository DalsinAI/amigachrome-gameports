then its own64 **current** active, nonobsolete, lower-reactor designs. The candidate

The source's redundant preliminary slot scan has no gameplay write; actual proposer

For one pair, the checked complete allocation plan executes, including actual
unreferenced retirement when selected. If returned ID differs from source ID, the
caller genuinely repeats pruning against the already-staged flags and calls
upgrade_any_prototypes. The restricted human/auto-prune-OFF branch of that real
wrapper returns naturally after clearing its upgrade scratch. If IDs are equal,
those extra calls do not happen and the observed scratch is preserved. A new

ring cursor and base queues are supplied by the nested owning proposal, with the
outer selected/flags getters supplying the final repeated-prune result.

A real reactor popup lies **before** those final resets when a proposal was attempted
for the local map owner. That path returns `reactor_presentation_required` before
publishing any plan; no popup return is invented. Multiple eligible pairs return
`ordered_sequence_required`: they need genuine changing state between calls.
Existing/history/duplicate/reuse or negative proposer returns are also held here;
no fake UID is substituted and caller follow-up is not skipped. Live retirement,
SMAX naming provenance, AI/network/modal, auto-design and further discovery effects

All failures preserve the complete previous plan and all inputs/World records.
World/raw/decoded, rules, facts, labels, nested owned base arrays and repeated-prune
