# Ordered base allocation with real unreferenced retirement

This read-only plan extends the frozen inactive-slot allocation domain to actual
**active winners with no live actor references**. It does not grant World/session,
research, discovery, sharing, player, turn or persistence authority. Runtime mode,
multiplayer, difficulty and last-created observations remain data. Saved human and
auto-prune facts remain separate checked inputs. AI/network/modal paths, SMAX live
naming provenance and live-unit retirement effects remain typed held.

The inactive API is unchanged. The new API first delegates its complete supported
path; only its genuine `retirement_required` result enters active retirement. Exact
source slot scoring is repeated against the same unmodified inputs. The actual
winner is retained even when an easier inactive slot exists. It then joins:

1. Capture the prior active record. Run the qualified complete no-live-reference
   retirement stage: append its real raw ability/components to the actual ring,
   advance the selected faction cursor modulo64, remove/replace its entries in
   **every owner's** queues with original increment-after-removal/stale-tail
   behavior, and clear its active bit. Any actual referencing actor rejects.
2. Construct against that actual post-retirement record. The new construction
   binding requires the record to equal the owned prior record with only active
   bit1 cleared. It virtualizes that record for coverage and last-slot flags,
   rather than counting the retired design as still available. Existing snapshot
   construction is retained.
3. Prepare against the **pre-retirement** active record. Therefore it does not add
   the inactive-origin0x40 bit. Other difficulty/group/flags match the original.
4. Resolve the genuine base logical name against the changed ring, including the
   original adjacent prePrototype0 bytes used during suffix collision handling.
   The new history binding owns bounded input semantics; it does not manufacture
   SMAX Windows pointers. Existing snapshot naming APIs are retained. Nonreturning
   and overflow paths remain held. Store strncpy32/NUL31 and clear flag2.
5. Apply the qualified candidate-aware human pruning stage. Begin final production
   replacement from the **retirement-adjusted** queues, then replace own obsolete
   same-group entries. Preserve every other copied base field, queue tail, saved
   counter and resource account. Update observed last-created only if negative.

The result owns final selected record, all512 flags, full base records, full4096
ring and next ring cursor. It never mutates/clones a stale World or rechecks history
at the wrong phase. One control appends the exact new request to history during
retirement: the original's earlier history check has already passed, so construction
must continue. Errors and output/input/owned-array aliases preserve the entire old
plan, World and all caller facts. Capacity remains an explicit512 bases.
